# GRIB2 Template 5.3/7.3 strict unpacker

This project implements, from scratch in Python, a decoder for a binary stream made
of concatenated GRIB2 Section 5, Section 6 and Section 7 triples. It does not use
a GRIB decoder. Bit unpacking, group reconstruction, spatial differencing, bitmap
handling and rational scaling are implemented in `grib2_unpack/`.

## Accepted subset

- Data Representation Template 5.3 and Data Template 7.3 only.
- Group splitting method `1`; original field-value type `0`.
- Spatial differencing orders `1` and `2`.
- Missing-value management `0`, `1` and `2`. Substitute values are not applied.
- Positive group count, group-reference bit width, scaled-group-length bit width
  and extra-descriptor octet count.
- The number of non-missing packed values must be at least the differencing order.
- Bitmap indicators `0`, `254` and `255` only:
  - `0`: defines N bits and becomes the latest explicit bitmap;
  - `254`: reuses the latest explicit bitmap and is rejected if none exists;
  - `255`: means all N points are present and does not clear bitmap memory.
- Descriptor arrays are independently octet aligned. The last group's encoded
  length is consumed, but its true length comes from Section 5.
- Packed data groups are not octet aligned; all padding bits must be zero.
- Group-length sum and Section 5 `numberOfValues` must equal the effective
  bitmap's number of ones.
- Non-finite reference values, unsupported codes, truncation, wrong section
  order, invalid padding and trailing bytes are rejected.

## Output

Values are represented as exact reduced positive-denominator rational strings,
`p/q`, using

```text
(R + X * 2^E) * 10^(-D)
```

Missing values are the strings:

- `bitmap` — zero in the effective bitmap;
- `primary` — primary explicit missing sentinel;
- `secondary` — secondary explicit missing sentinel.

An empty input stream decodes to `[]`.

## Command-line entry point

```bash
# Installed package or a checkout whose current directory is on sys.path
python3 -m grib2_unpack N input.bin -o output.json

# Isolated execution directly from an uninstalled checkout
python3 -I grib2_unpack/__main__.py N input.bin -o output.json
```

The output file is written through a same-directory temporary file and atomic
`os.replace`; a failed decode leaves any previous output unchanged.

## Python API

```python
from grib2_unpack import unpack_stream, GribParseError

fields = unpack_stream(4, stream)
```

`GribParseError.offset` is the zero-based byte offset of the erroneous section.
A missing section reports the input length. An invalid caller-supplied `N` is
reported with parameter name `N`.

## Acceptance tests and byte fixtures

Run the full independent suite:

```bash
python3 -I -m unittest discover -v
```

Regenerate the raw byte fixtures and expected JSON files:

```bash
python3 -I tools/generate_fixtures.py
```

The fixtures under `tests/fixtures/` are raw bytes generated by the standalone
bit writer in `tests/build_fixtures.py`; no GRIB library is involved. They cover
numeric reconstruction, bitmap/primary/secondary missing classification,
rejection and error offsets.

If ecCodes is installed in the environment, an optional numeric intersection
check is available:

```bash
python3 -I tools/cross_check_eccodes.py
```

Without ecCodes, that script prints a skip message while the main acceptance
suite remains fully runnable.
